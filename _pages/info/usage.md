## Запуск Kefir Hub

**Kefir Hub** — головний застосунок збірки: через нього запускаються homebrew-додатки, встановлюються ігри, робляться резервні копії збережень, завантажуються чити й теми, оновлюються Kefir і прошивка. Сам Kefir Hub — homebrew-додаток (`/switch/kefir-hub.nro`), тому запускається через Homebrew Menu, як і будь-яке хомбрю.
{: .notice--info}

{% include /inc/launch-hbl.md %}

Якщо відкрилося класичне Homebrew Menu, виберіть у ньому **Kefir Hub**. Ви, як і раніше, можете використовувати й Альбом, однак рекомендується запускати Kefir Hub через гру або форвардер: так йому доступна вся пам'ять консолі, і великі ігри встановлюватимуться без проблем.
{: .notice--info}

На головному екрані Kefir Hub дві вкладки: **Homebrew** (ваші додатки) та **Інструменти** (усе інше). Перемикаються вони кнопками {% include /inc/btn.txt btn="L" %} / {% include /inc/btn.txt btn="R" %}.

[Детальніше про Kefir Hub](/hbl){:target="_blank"}

## Встановлення ігор

Усі способи встановлення ігор (з карти пам'яті, з ПК по USB, через MTP, по мережі), а також місця, де ігри брати, знаходяться тут — [Встановлення ігор](/games){:target="_blank"}.

* Перед першим встановленням його потрібно увімкнути: **Інструменти** → **Налаштування** → **Встановити** → **Увімкнути на sysMMC** або **Увімкнути на emuMMC** (залежно від того, що у вас запущено) {% comment %}TODO: plan D.2 removes the install switch{% endcomment %}
* **Видалення ігор**: **Інструменти** → **Ігрові інструменти** → **Ігри**, наведіть курсор на гру, натисніть {% include /inc/btn.txt btn="+" %} → **Видалити**. Збереження при цьому залишаються

## Збереження

Резервні копії збережень робляться в **Інструменти** → **Ігрові інструменти** → **Збереження**: наведіть курсор на гру, натисніть {% include /inc/btn.txt btn="A" %} → **Створити резервну копію**. Там само їх і відновлюють. Kefir Hub бачить і копії, зроблені в DBI, JKSV та Checkpoint.

Детальніше — [Резервне копіювання та відновлення збережень](/backup-saves){:target="_blank"}

## Чити

Чити завантажуються в **Інструменти** → **Ігрові інструменти** → **Чити**: повний набір (**Завантажити чити Kefir**) або чити для конкретної гри (**Завантажити точні чити**). Вмикаються чити вже в самій грі, через оверлей EdiZon у Tesla-меню.

Детальніше — [Використання читів](/cheats){:target="_blank"}

## Теми

Теми для головного меню консолі завантажуються в **Інструменти** → **Теми** (готові набори або каталог **Themezer**), а застосовуються через NXThemes Installer, який Kefir Hub відкриває сам.

Детальніше — [Kefir Hub: теми](/hbl#теми){:target="_blank"}

## Оновлення

### Оновлення Kefir

Найпростіше — прямо на приставці: **Інструменти** → **Оновлювач**, розділ **KEFIR** (потрібен інтернет). Інші способи — [інструкція з оновлення kefir](/kefir#інструкція-з-встановленняоновлення-kefir){:target="_blank"}.

### Оновлення системного ПЗ

Оновлювати системне ПЗ можна **тільки** після оновлення kefir, інакше прошивка може не запуститися! Kefir Hub сам запропонує спершу оновити Kefir, якщо вибрана версія прошивки ним ще не підтримується.
{: .notice--warning}

Детальна інструкція з оновлення знаходиться тут - [Безпечне оновлення прошивки](/update-fw){:target="_blank"}

### Оновлення Kefir Hub

Kefir Hub перевіряє наявність власної нової версії під час запуску і за замовчуванням завантажує її у фоні. Налаштовується це в **Інструменти** → **Налаштування** → **Загальний**. Детальніше — [документація]({{ site.kefir_hub_docs }}/uk/updater/#update-kefir-hub){:target="_blank"}.

## Доступ до файлів з ПК

Щоб скопіювати файли на карту пам'яті чи з неї, не виймаючи її з приставки, у Kefir Hub є три способи:

* **MTP** — підключіть консоль до ПК USB-кабелем; карта пам'яті з'явиться в Провіднику, як телефон
* **FTP** — по Wi-Fi, через FTP-програму на ПК
* **Браузер** — по Wi-Fi, через вебсторінку, яку відкриває Kefir Hub

Детальніше — [Доступ до файлів з ПК](/ftp){:target="_blank"}
