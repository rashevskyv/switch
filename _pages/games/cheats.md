Чити завантажуються та керуються в **Kefir Hub** ("**Інструменти**" → "**Ігрові інструменти**" → "**Чіти**"), а вмикаються і вимикаються вже в самій грі через **Tesla**-меню.

Чити кожної гри прив'язані до її версії (**Build ID**). Після оновлення гри старі чити перестають працювати — див. [нижче](#після-оновлення-гри)
{: .notice--info}

## Завантаження читів

Для завантаження читів інтернет має бути підключений та працювати
{: .notice--warning}

1. Оновіть {% include abbr/kefir_addr.txt %}, якщо не робили цього раніше
1. Запустіть [Kefir Hub](/hbl){:target="_blank"}
1. Натисніть {% include /inc/btn.txt btn="R" %}, щоб перейти на вкладку "**Інструменти**", і відкрийте "**Ігрові інструменти**" → "**Чіти**"
1. Оберіть спосіб завантаження:
	* "**Завантажити чити Kefir**" — повний набір читів для багатьох ігор одразу. Підтвердіть кнопкою "**Завантажити**" та дочекайтеся повідомлення "**Пакет читів встановлено**"
	* "**Завантажити чити 60FPS/GFX**" — набір читів на частоту кадрів, роздільність і графіку. Встановлюється так само
	* "**Завантажити точні чити**" — чити для однієї гри під її поточну версію (див. нижче)

{% comment %}shot: cheats-menu{% endcomment %}

Повні набори перезаписують наявні файли читів з такими самими назвами
{: .notice--warning}

### Чити для однієї гри

Найнадійніше Kefir Hub визначає версію гри, якщо її хоча б раз запускали. Тож спершу запустіть гру, закрийте її, а потім завантажуйте чити
{: .notice--info}

1. У меню "**Чіти**" оберіть "**Завантажити точні чити**"
1. Наведіть курсор на гру та натисніть {% include /inc/btn.txt btn="A" %}
1. Позначте потрібні чити кнопкою {% include /inc/btn.txt btn="A" %}
	* {% include /inc/btn.txt btn="X" %} — вибрати все
	* {% include /inc/btn.txt btn="R" %} — переглянути код чита
1. Натисніть {% include /inc/btn.txt btn="Y" %} та підтвердіть завантаження

{% comment %}shot: cheats-select{% endcomment %}

Якщо з'явилося "**Читів не знайдено**", у базі немає читів для цієї гри або для її версії.

Власний файл читів (`.txt`), скопійований на карту пам'яті, можна додати пунктом "**Імпортувати з файлу**" ([докладніше]({{ site.kefir_hub_docs }}/uk/cheats/#import-a-cheat-file){:target="_blank"})

## Після оновлення гри

Якщо гру оновили, а чити перестали працювати:

1. У меню "**Чіти**" оберіть "**Переглянути чити**"
1. Наведіть курсор на гру та натисніть {% include /inc/btn.txt btn="A" %}
1. Наведіть курсор на файл читів та натисніть {% include /inc/btn.txt btn="Y" %} ("**Виправити BID**"), потім підтвердіть

{% comment %}shot: cheats-files{% endcomment %}

Файл лише перейменовується під нову версію, коди всередині не змінюються, тож старі чити на новій версії можуть не працювати або працювати неправильно. Краще завантажити чити для нової версії знову
{: .notice--warning}

Там же, у "**Переглянути чити**", чити можна видаляти: {% include /inc/btn.txt btn="X" %} на файлі читів або {% include /inc/btn.txt btn="Y" %} на грі. Чити видалених ігор прибирає пункт "**Видалити застарілі чити**". Докладніше — у [документації Kefir Hub]({{ site.kefir_hub_docs }}/uk/cheats/#delete-cheats){:target="_blank"}

## Робота з читами

1. Запустіть гру, для якої хочете застосувати чит
1. Одночасно натисніть {% include /inc/btn.txt btn="L" %}+{% include /inc/btn.txt btn="DOWN" %}+{% include /inc/btn.txt btn="R3" %}, щоб відкрити **Tesla**-меню 
1. Виберіть "**EdiZon**" -> "**Cheats**"
1. За замовчуванням всі чити відключені, увімкніть потрібні
   + Після перезапуску гри, чити, які ви активували раніше, також будуть активні!
   + Щоб уникнути завантаження непотрібних читів, відключіть всі наявні чити перед завантаженням сейва гри, а потім, після того, як сейв буде завантажений, активуйте тільки потрібні. 
1. Закрийте Tesla кнопкою {% include /inc/btn.txt btn="B" %}
1. Для відключення чита знову зайдіть в **Tesla** -> "**EdiZon**" -> "**Cheats**" та відключіть чит
