**Kefir Hub** — головний застосунок збірки Kefir. Він запускає ваші homebrew-додатки (`.nro`), встановлює ігри, робить резервні копії збережень, завантажує чити й теми, керує профілями користувачів, оновлює Kefir і прошивку, а також відкриває карту пам'яті на ПК. Усе це — на самій консолі, в одному місці.

Kefir Hub — звичайний homebrew-додаток, тому він запускається так само, як будь-яке хомбрю: через **Homebrew Menu** (**HBMenu**, **Homebrew Launcher**, **HBL**). Сам файл лежить на карті пам'яті за шляхом `/switch/kefir-hub.nro`.

Повний опис усіх функцій — у [документації Kefir Hub]({{ site.kefir_hub_docs }}/uk/){:target="_blank"}. На цьому сайті — короткі покрокові інструкції.

## Режим аплету та режим тайтлу

Homebrew можна запустити у двох режимах:

* **Режим аплету** — запуск з **Альбому**. Додатку доступна лише невелика частина пам'яті консолі. Kefir Hub працює, але великі стиснені ігри (NSZ), найімовірніше, не встановляться, а вебсервер працює повільніше.
* **Режим тайтлу** — запуск через гру з утриманою {% include /inc/btn.txt btn="R" %} або з іконки-форвардера на головному екрані. Додатку доступна вся пам'ять, він запускається як гра.

Для встановлення ігор і всього «важкого» запускайте Kefir Hub у режимі тайтлу.
{: .notice--warning}

## Запуск Kefir Hub

{% include /inc/launch-hbl.md %}

Якщо відкрилося класичне Homebrew Menu, виберіть у списку **Kefir Hub** і натисніть {% include /inc/btn.txt btn="A" %}. Якщо Homebrew Menu замінено на Kefir Hub, він відкриється одразу.

{% spoiler Як зробити, щоб замість Homebrew Menu одразу відкривався Kefir Hub %}

1. У Kefir Hub перейдіть до **Інструменти** → **Налаштування** → **Homebrew**
1. Увімкніть **Заміна hbmenu при виході**
   * Тепер під час кожного виходу Kefir Hub копіює себе в `/hbmenu.nro`, тож Альбом і гра з утриманою {% include /inc/btn.txt btn="R" %} одразу відкривають Kefir Hub
   * Щоб повернути старе Homebrew Menu, вимкніть цей перемикач: Kefir Hub спитає **Відновити hbmenu?** і відновить його з `/switch/hbmenu.nro`

{% endspoiler %}

### Перший запуск

1. Виберіть мову. Пізніше її можна змінити в **Інструменти** → **Налаштування** → **Загальний** → **Мова** (після зміни Kefir Hub запропонує перезапуститися)
1. Якщо якісь профілі користувачів на консолі не прив'язані до облікового запису Nintendo, Kefir Hub запропонує їх прив'язати. Детальніше — [Прив'язка облікового запису](/link-account){:target="_blank"}

## Homebrew-додатки

На вкладці **Homebrew** видно всі `.nro` з папки `/switch/` на карті пам'яті (і з її підпапок на один рівень нижче). Наведіть курсор на додаток і натисніть {% include /inc/btn.txt btn="A" %} — Kefir Hub закриється й запустить його. Сортування, вигляд списку, обране й видалення — у панелі {% include /inc/btn.txt btn="+" %}.

{% include inc/hub-shot.html id="homebrew-grid" %}

### Встановлення додатків

* Скопіюйте файл `.nro` в папку `/switch/` на карті пам'яті
   * Виймати карту не обов'язково: підключіть консоль до ПК кабелем (MTP) або по мережі — див. [Доступ до файлів з ПК](/ftp){:target="_blank"}
* Щоб Kefir Hub показував додатки й з інших папок, додайте їх у **Інструменти** → **Налаштування** → **Homebrew** → **Шляхи пошуку Homebrew**

#### Встановлення додатків через інтернет

1. Запустіть Kefir Hub
   * Інтернет має бути підключеним і працювати
1. Натисніть {% include /inc/btn.txt btn="R" %}, щоб перейти на вкладку **Інструменти**
1. Виберіть **Додаткові програми** → **Homebrew App Store**
1. Виберіть потрібну програму та встановіть її
   * Встановлений додаток з'явиться на вкладці **Homebrew**

Там само, у **Додаткові програми**, можна завантажити DBI, завантажувачі модів і будь-який `.zip` чи `.nro` за прямим посиланням. Детальніше — [документація]({{ site.kefir_hub_docs }}/uk/software/){:target="_blank"}.

### Форвардери

Форвардер — це іконка на головному екрані консолі, яка запускає homebrew напряму, у режимі тайтлу.

1. На вкладці **Homebrew** наведіть курсор на додаток
1. Натисніть {% include /inc/btn.txt btn="+" %} і виберіть **Встановити форвардер**
1. Поверніться на головний екран консолі — там з'явиться нова іконка

Форвардер встановлюється як гра, тому Kefir Hub спершу попросить увімкнути встановлення і попередить про ризик бану. Форвардер для рому гри можна зробити у **Файловому браузері**. Детальніше — [документація]({{ site.kefir_hub_docs }}/uk/homebrew/#add-an-app-to-the-home-menu-forwarder){:target="_blank"}.

## Асоційовані файли

Асоціації файлів пов'язують розширення файлів (`.gba`, `.txt` тощо) з homebrew-додатком. Наприклад, натискання {% include /inc/btn.txt btn="A" %} на `rom.gbc` у **Файловому браузері** відкриє список усіх програм, які можуть його обробити. Це зручно для емуляторів, медіаплеєрів, текстових редакторів тощо.

Користувацькі асоціації файлів повинні знаходитися в папці `/config/kefir/assoc/`

Формат *дуже* простий, ось приклад `vgedit.ini`:

```ini
[config]
supported_extensions=txt|json|cfg|ini|md|log
```

І ще один для `mgba.ini`:

```ini
[config]
supported_extensions=gba|gbc|sgb|gb
database=Nintendo - Game Boy|Nintendo - Game Boy Color|Nintendo - Game Boy Advance
```

* **path** (необов'язково): повний шлях до `.nro`. Якщо не вказано, використовується ім'я ini файлу, тобто `mgba.ini` використовуватиме `mgba.nro`.
* **supported_extensions**: список розширень, які підтримує програма, розділених символом `|`.
* **database** (необов'язково): назва бази даних ромів, визначена лівою частиною [цієї таблиці](https://gist.github.com/ITotalJustice/d5e82ba601ca13b638af9b00e33a4a86){:target="_blank"}.

Додаток має бути на карті пам'яті. Детальніше — [документація]({{ site.kefir_hub_docs }}/uk/file-browser/#open-a-file-in-another-app){:target="_blank"}.

### Роми

Роми слід розміщувати в `/roms/system_name/`, де "**system_name**" визначається записами у правій частині [цієї таблиці](https://gist.github.com/ITotalJustice/d5e82ba601ca13b638af9b00e33a4a86){:target="_blank"}, наприклад `/roms/snes/` або `/roms/gba/`. Kefir Hub пропонує лише ті ядра емуляторів, що підтримують цю систему й тип файлу.

Це той самий макет, який використовує emulation station. Причина, з якої роми мають лежати в конкретних папках, полягає в тому, що багато ромів для різних систем використовують одне й те саме розширення файлів, наприклад, `.bin / .cue` або `.chd`.

Дозволяється також розміщувати роми в підпапках. Наприклад, `/roms/psx/scooby-doo/scooby-doo.bin` є валідним шляхом.

## Теми

{% include inc/hub-shot.html id="themes-list" %}

1. Відкрийте **Інструменти** → **Теми**
1. Виберіть готовий набір або **Themezer** (каталог тем із themezer.net) і завантажте тему
   * Теми зберігаються в папці `/themes/` на карті пам'яті
1. На запит **Тему завантажено. Встановити зараз?** виберіть **Встановити** — відкриється NXThemes Installer, у якому й завершується встановлення теми

Під час встановлення прошивки через **Оновлювач** власні теми видаляються — після оновлення встановіть їх знову. Детальніше — [документація]({{ site.kefir_hub_docs }}/uk/themes/){:target="_blank"}.
